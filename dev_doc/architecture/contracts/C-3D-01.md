# C-3D-01 — A 3D geometry handed to Optiland must be differentiable

**Assumptions.** A geometry registered with Optiland as a plugin supplies
a *backward pass* — the ability to compute how the trace changes when the
geometry changes — not only a forward trace.

**Guarantees.** Given that, a design can be *polished* against a 3D merit
function by gradient methods, not only checked.

**Invariants.** A mesh built by revolving sample points is forward-only.
It can be traced through; it cannot be differentiated. Supplying one
silently forfeits the gradient.

**Units and frames.** Not applicable.

**If the assumption is violated.** Deferred: the failure appears only when
an optimisation step is attempted, not when the geometry is registered.

**Checked by.** Nothing yet; the plugin is not built.
