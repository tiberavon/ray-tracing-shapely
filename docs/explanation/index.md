# Explanation

Why the code is shaped the way it is. Thirty-six concepts, each a screen or
two, each with a key (`KA1`, `KD10`) that the architecture pages and the
code's own docstrings cite. The same tree lives at `dev_doc/concepts/` in
the repository and is included here at build.
