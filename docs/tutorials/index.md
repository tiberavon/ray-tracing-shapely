# Tutorials

Executed examples, from a first scene upwards. The first is the README's
Quick Start, run end to end; the
[README](https://github.com/tiberavon/ray-tracing-shapely) carries it today.

Three example notebooks are published with the repository, under
`notebooks/`:

- `abbe_refractometer_example.ipynb`
- `critical_ray_path_refractometer_example.ipynb`
- `chapter21_geometry_toolbox_example.ipynb`

The project's other notebooks are its working records and are not
published. Tutorials added here are written for this section, not copied
from them.
